## 二、产品目标

1. **提升长文档导航效率**：通过左侧目录大纲，让用户在长篇 Markdown 中快速定位章节，且编辑区与预览区同步滚动到对应位置。
2. **支持多文档并行工作**：在顶部提供多标签栏，允许同时打开多个 Markdown 文件并快速切换，减少反复打开/关闭文件的上下文切换成本。
3. **强化品牌识别与一致性**：在现有标识前注入中文品牌名"墨览"，并顺手验证、补齐悬浮复制能力，使产品更像完整的桌面编辑器。

## 三、用户故事

1. 作为一名技术写作者，我希望左侧有大纲，点击章节后编辑器和预览都跳转到对应位置，以便在长文中快速修改和核对内容。
2. 作为一名需要对比多份文档的用户，我希望顶部能像浏览器一样开多个标签切换不同 MD 文件，避免频繁使用文件对话框。
3. 作为一名读者，我希望在预览区看到大段文字或表格时，鼠标悬浮即可复制，无需手动框选，减少误操作。
4. 作为一名首次安装的用户，我希望在标题栏、关于框、安装包和快捷方式中看到一致的品牌名"墨览 YiQi@MD-Editor-wb-Hy3"，建立品牌印象。
5. 作为一名日常使用者，我希望版本号能随功能迭代自然递增，从更新提示中感知产品演进。

## 五、UI/UX 说明

### 5.1 左侧目录大纲

- **位置**：窗口最左侧，位于编辑区与预览区之外，可折叠或固定宽度（建议默认宽度 220px，可拖拽调整）。
- **内容**：按标题层级缩进显示 H1–H6 文本，过长标题省略并 tooltip 显示完整文本。
- **交互**：
  - 单击条目 → 编辑区滚动到对应行并定位光标，预览区滚动到对应锚点。
  - 滚动编辑区或预览区时，大纲自动高亮当前可见的最近章节。
  - 空文档/无标题时显示"暂无目录"占位，不展示空白。
- **视觉**：当前高亮条目使用主色背景或左边框，层级缩进清晰，与主题系统保持一致。

### 5.2 顶部多标签栏

- **位置**：TopBar 品牌区下方、编辑区上方（或合并到 TopBar 第二行）。
- **标签内容**：文件名 + 关闭按钮；未保存时在文件名后显示圆点或星号（`*filename.md`）。
- **交互**：
  - 点击标签切换文档。
  - 中键或点击关闭按钮关闭标签；关闭未保存文档时弹窗提示"是否保存"。
  - 仅剩一个标签时关闭行为等价于"新建空白文档"或保持空白标签（建议后者，避免窗口关闭）。
  - 支持 Ctrl+Tab / Ctrl+Shift+Tab 切换下一个/上一个标签。

### 5.3 悬浮复制按钮（大段文字）

- **触发范围**：
  - 已覆盖：预览区代码块（`CopyButton`）、关于框描述（`CopyableBlock`）、状态栏文件路径（`CopyableBlock`）、错误提示（`CopyableBlock`）。
  - 需补齐：预览区长段落（`p`）、引用块（`blockquote`）、表格（`table`）、有序/无序长列表、代码块外的 Mermaid 源码说明。
- **交互**：鼠标悬浮目标块右上角浮现 `📋 复制` 按钮；点击后按钮变为 `✓ 已复制` 并 1.5s 复位；失败后显示轻提示"复制失败，请重试"。
- **设计**：按钮不遮挡正文，暗色/浅色/纸张/石墨/午夜主题下均清晰可见；尊重 `prefers-reduced-motion`。

### 5.4 品牌名展示

- 标题栏/Logo 区：`📝 墨览 YiQi@MD-Editor-wb-Hy3`。
- 窗口标题：`文件名.md — 墨览 YiQi@MD-Editor-wb-Hy3`。
- 关于框：`墨览 YiQi@MD-Editor-wb-Hy3 v1.1.0`。
- 安装包/快捷方式显示名：`墨览 YiQi@MD-Editor-wb-Hy3`。

## 六、品牌名"墨览"应用建议与版本号建议

### 6.1 "墨览"应用位置

| 位置 | 建议展示形式 | 备注 |
| --- | --- | --- |
| **顶部标题栏 / Logo 区**（截图区域） | `墨览 YiQi@MD-Editor-wb-Hy3` | 按需求在 `YiQi` 前加"墨览"，保留原有 `@` 与 `wb-Hy3` 后缀。 |
| **窗口标题（任务栏/运行标题）** | `文件名.md — 墨览 YiQi@MD-Editor-wb-Hy3` | 品牌名前置，文件变化时只改文件名部分。 |
| **关于框** | `墨览 YiQi@MD-Editor-wb-Hy3 v1.1.0` | 使用全名，版本号单独一行或同一行均可。 |
| **安装包显示名 / 桌面快捷方式** | `墨览 YiQi@MD-Editor-wb-Hy3` | 用户可见的安装向导与开始菜单名称。 |
| **exe / 安装包文件名** | 建议保留 ASCII 字符，可改为 `MoLan-YiQi-MD-Editor-wb-Hy3-Setup-1.1.0.exe` 或沿用 `YiQi-MD-Editor-wb-Hy3-Setup-1.1.0.exe` | Windows 与 NSIS 对中文文件名支持虽好，但为兼容某些网盘/命令行路径，文件名用拼音或保持原 ASCII 更安全；**显示名**用中文即可。 |
| **index.html `<title>`** | `墨览 YiQi@MD-Editor-wb-Hy3` | 开发态浏览器 tab 与打包后一致。 |
| **package.json `name`** | 可保持 `yiqi-md-editor-wb-hy3` 不变 | npm 包名限制（小写、无 `@`、无大写、无中文），内部标识不需要随显示名改变。 |
| **electron-builder `appId`** | 可保持 `com.mdeditor.app` 或改为 `com.molan.yiqi.md-editor-wb-hy3` | 若已发布安装包且希望自动更新识别旧版本，建议保留；仅新装包可改。 |

### 6.2 版本号递增建议

- **建议升级到：`1.1.0`**
- **理由**：
  - 本轮新增目录大纲、多标签两大用户可见功能，属于功能性 MINOR 更新，按 SemVer 语义应提升中间位。
  - `1.0.1` 更适合纯 BUG 修复热更新；本轮除了复制功能验证兜底外，还有品牌名更新与功能扩展，用 `1.1.0` 更能向用户传达"这是一次功能迭代"。
- **必须同步的位置**：`package.json`、`src/shared/constants.ts`（`APP_VERSION`）、`tests/constants.test.ts` 中关于 `APP_DISPLAY_NAME` 的断言、`electron-builder.yml` 产物名（已通过 `${version}` 模板自动跟随）。

## 七、边界与异常处理

| 场景 | 处理建议 |
| --- | --- |
| 大纲目标标题在编辑区被删除或修改 | 重新提取大纲；若点击的条目已不存在，给出轻提示"该标题已失效"，并刷新大纲。 |
| 多标签下某文档被外部删除 | 切换或保存时检测文件不存在，提示"文件已被移动或删除，是否另存为？"。 |
| 多标签下关闭未保存文档 | 弹窗三选一：保存 / 不保存 / 取消关闭。 |
| 同时打开大量标签 | 标签栏超出宽度时支持横向滚动，不挤压 TopBar 其他控件。 |
| 复制失败（剪贴板不可用/权限被拒） | 不仅静默兜底，还需通过 toast 或按钮 tooltip 提示用户"复制失败"；回退到 `navigator.clipboard.writeText`。 |
| 大段文字为空或仅空白 | 悬浮复制按钮可隐藏或置灰，避免用户点击后复制空字符串。 |
| 无标题文档 | 大纲区显示占位"暂无目录"，不报错、不塌陷布局。 |
| 版本号与测试契约不同步 | 升级版本时同步更新 `tests/constants.test.ts`，否则 `npm test` 会红。 |

## 八、待确认问题

1. **多标签的关闭策略**：关闭最后一个标签时是直接关闭窗口、还是保留一个空白未命名文档？（建议保留空白文档，避免误关窗口。）
2. **大纲是否支持折叠/隐藏**：用户是否需要在窄屏下完全隐藏大纲，或折叠到图标栏？
3. **标签页是否持久化**：下次启动时是否恢复上次打开的标签页？（建议本轮不持久化，降低复杂度；后续迭代再考虑会话恢复。）
4. **中文品牌名是否进入文件名**：安装包/快捷方式/exe 文件名是否也要带"墨览"中文？（建议显示名用中文，文件名保持 ASCII 兼容。）
5. **复制按钮覆盖的精确范围**：是否覆盖编辑器源码区？（建议本轮不覆盖编辑区，仅覆盖只读预览区与展示型文本，避免与原生选中文本复制冲突。）
